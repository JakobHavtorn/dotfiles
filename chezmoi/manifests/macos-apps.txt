# macos-apps.txt — self-updating macOS apps installed from the vendor's download
# Format: app_bundle|url|bin_in_bundle
# app_bundle:    the .app name at the root of the DMG or zip
# url:           a vendor URL that always serves the latest release (DMG or zip;
#                the format is detected from the file, not the URL), or
#                squirrel:<feed-url> — an Electron/Squirrel update feed
#                (RELEASES.json); the installer resolves the newest release
#                zip from the feed before downloading
# bin_in_bundle: path inside the bundle to a CLI to link into ~/.local/bin,
#                or - for none
# Installed only when missing from /Applications and ~/Applications; the
# app's own updater keeps it current. Use this instead of a Brewfile cask
# when the app's updater takes ownership of the bundle away from the user,
# which breaks `brew upgrade --cask` for a non-admin user.
# Lines starting with # are comments
